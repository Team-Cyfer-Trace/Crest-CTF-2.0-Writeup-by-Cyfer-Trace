## Challenge description

The Keymaster appliance is the identity broker for an archival estate: it bridges a legacy Windows file share, a key-attestation service, and a modern single sign-on front end. Three teams, three eras, three real bugs. A packet capture from the file-share subnet contains a Windows NTLM logon -- not a cleartext password, but a NetNTLMv2 challenge/response that can be cracked offline against a small leaked wordlist. The archivist credential it yields unlocks a key-attestation service whose elliptic-curve parameters were generated by a well-meaning intern: the curve is anomalous (its group order equals the field prime), so the private key falls straight out of the public key via Smart's attack. And that private key is the confidential-client secret for an OAuth2 authorization server whose redirect_uri check is a loose substring match -- craft a callback that passes it, steal the admin authorization code, and trade it for an admin token. This is a three-stage chain -- Network then Crypto then Web -- where each stage's output is the next stage's key. Recover the flag from the OAuth admin endpoint. Access:Stage 1: http://2.31.70.16:16220/Stage 2: http://2.31.70.16:16221/Stage 3: http://2.31.70.16:16222/
